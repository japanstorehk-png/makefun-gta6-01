Solara Keys is an original offline open-world crime game set in Costa Luna. Walk or drive, take jobs from fixer Mara Quill, and lose the Luna PD. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## What's in the box

- Title screen, walk/drive on a seeded road graph, four staged screenshots (`shots.json`).
- Jobs from Mara Quill, wanted level 0–5 with police pursuit and gunfire, HUD with minimap and health.
- Progress saves to this browser on pause or close; press N on the title screen to start fresh.

## Run it

```sh
node serve.ts
```

Then open http://127.0.0.1:8080/ in a desktop browser. Keyboard and mouse. No network is required after the files are served.
