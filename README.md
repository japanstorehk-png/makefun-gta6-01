**Solara Keys** is an original offline 2D open-world crime game set in **Costa Luna**. Work for fixer **Mara Quill**, steal and deliver cars, complete a case drop while dodging **Luna PD**, and take on free-roam side jobs across Hotel Azure, Costa Marina, Mirador Park, Solara Heights, the warehouse, the dock, and the plaza.

## Run locally

```sh
node serve.ts
```

Then open http://localhost:8080
