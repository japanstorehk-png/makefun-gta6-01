**Solara Keys** is an original offline open-world crime game set in **Costa Luna**. Work with fixer **Mara Quill**, outrun **Luna PD**, steal cars, complete jobs, and take on side deliveries across a small seeded 2D city built with plain HTML canvas and JavaScript modules.

## Play locally

```bash
node serve.ts
```

Then open [http://localhost:8080](http://localhost:8080).
